Lumen Factory

This site is built with Python on your machine, then exported to plain HTML. Terraform publishes that folder to AWS. The pages you are reading are the product. S3 and CloudFront come later in the lesson and serve these same files.

No databaseNo server in productionHTTP first, HTTPS next

Forge locally

Preview the pages, change the copy, and run the static build. app/dist/ is the only artifact Terraform uploads.

02

Apply the stack

One module creates a private bucket, a CloudFront distribution, and the objects inside the bucket. Dev and prod each have their own state.

03

Open the URL

The useful output is cloudfront_url. It is HTTPS. The S3 website endpoint from the first lesson is gone on purpose.

What you are looking at

If this page loaded from 127.0.0.1, Python rendered it. If it loaded from a CloudFront domain, Terraform uploaded the exported HTML. The words stay the same either way. Nothing here calls AWS.
