Learning goals

What this factory teaches

One visible site, iterated. Each idea in Terraform shows up as a change you can open in a browser or read in a plan.

  1. Providers

    The AWS provider talks to one account and region. CloudFront certificates are the exception: ACM for a distribution has to live in us-east-1, so that region is a second provider alias.

  2. State

    State is Terraform's memory of what it created. It starts as a local file, then moves to an S3 bucket with a DynamoDB lock. The state bucket is not the website bucket.

  3. Modules

    modules/static_site owns the bucket, the distribution, and the uploads. Environment folders only call that module and pass variables.

  4. Environments

    Dev and prod are separate roots with separate state keys. They share the module. They do not share a tfvars file. Workspaces are a different tool and this lesson does not use them.

Left out of v1

No Kubernetes, no containers, no database, no VPC, no NAT gateway, no WAF, and no access logs. Those hide the thing this repo is for: a URL that came from a plan.
